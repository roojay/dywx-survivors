# 首个玩法原型：三到五分钟清怪变强

> 2026-10-26 · 当前验证范围 · 玩法草案，尚未试玩  
> 后续内容参考[完整设计](game-design.md)。

## 只验证一件事

**走位清怪 → 获得强化 → 清怪明显更爽，能否让玩家想再玩一次？**

## 最小内容

- **角色与操作：**断岳行者，自动攻击，玩家负责移动和遁术。
- **场地：**一块开阔的古坛，保留东方神话名称与氛围。
- **敌人：**普通追兵接近玩家；精英先停顿、显示冲锋方向，再沿该方向冲锋。
- **三项技能：**断岳三叠为起手近身连斩；回风刃环提供环绕清场；穿云重矢提供远程贯穿。
- **两件遗珍：**磨砺石提高伤害，须弥镜扩大斩击与刃环范围、加宽重矢。精英随机掉其中一件，拾取立即生效。

## 三波体验

| 波次 | 玩家经历什么 | 波后得到什么 |
| --- | --- | --- |
| 第一波，约 60 秒 | 少量追兵，熟悉移动、自动斩击与拾取经验。 | 一次悟法：升级断岳三叠，或学习回风刃环、穿云重矢。 |
| 第二波，约 60—90 秒 | 追兵增加，出现一只冲锋精英；用新能力清怪，用走位或遁术躲冲锋。击败精英后结束本波。 | 拾取遗珍，再完成一次悟法：从三项技能的有效学习或升级选项中选一项。 |
| 第三波，约 60—90 秒 | 普通怪更密集，生命值保持不变，让刚获得的技能与遗珍兑现清场提升。 | 坚持到波次结束即成功；可以立即再开。 |

前两波的经验量先按正常清怪各获得一次悟法安排，选择集中在安全整备期。阶段计时是候选节奏；第二波须击败精英，实际时间可浮动。普通波结束时残敌退场、危险清除，撤退不计击杀。死亡立即结算，可重新尝试。

强化要容易看见：伤害提升应减少击杀所需攻击次数；范围提升应明显扩大覆盖。重点观察学习新攻击与升级旧攻击的取舍。

## 试玩只看三件事

1. 玩家能否指出自己获得了什么强化，以及战斗哪里变了？
2. 第三波清群是否明显更利落，走位是否仍然有作用？
3. 结束后，玩家是否想换一个选择再试？

每轮先改最影响体验的一项，再重玩同一小段。先用这一页排清体验；清怪手感与再玩意愿需要实际可玩原型验证。成立后再从完整方案中选一项内容扩充。
