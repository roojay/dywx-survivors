# 东方神话幸存者世界观与首发玩法设计

> 文档状态：完整玩法构想与内容储备。当前先按[首个玩法原型](first-playable-prototype.md)验证三到五分钟的核心循环。
> 更新日期：2026-10-26

本作以东方神话中的洞天劫潮承载幸存者玩法：玩家选择角色与洞天，以移动和遁术调整战场，自动施展术法，在波后悟法、遗珍掉落与道象联动中逐渐成型。首批内容保留断岳行者、巡星羽客、司霆方士、归灵祝师四名角色，合计 24 项攻击技能、28 件遗珍、3 处洞天和 8 条成型示例。

本版整合清怪兑现、四档遗珍、关键奖励保障、衔珍灵兽、阶段风险抉择和两条轻量道象。体验优先级为清怪爽感、稀有掉落惊喜、组合发现，环境认知贯穿战斗。首发内容目录与首轮原型范围分别定义；时长、波数、触发间隔和成长幅度作为试玩校准参数。

## 世界观与体验定位

沿用《道衍万象》的核心命题：**神话为表，科技为里；探索为引，认知为赏。** 本作让“探索”主要发生在战斗中的观察、验证与重新理解：一次异象先成为需要躲避的危险，随后成为可以利用的清怪手段，最后让玩家发现洞天之间的共同秩序。

对玩家的开场表述可以是：“洞天将倾，劫潮复起。携本命之法入境，纳散落之灵蕴，借古物之道纹，在万象失序中杀出一线生机。”

### 三条背景原则的玩法落点

| 背景原则 | 本作中的具体做法 |
| --- | --- |
| 神话优先 科技隐脉 | 人物、异兽、法器、异象和游戏内叙述使用仙侠语言。隐藏成因只在策划层规定，用一致的节律、纹样和行为留下证据。 |
| 世界可读 真相可探 | 每张地图围绕一个能够反复验证的规律展开。玩家通过走位、引怪和击杀精英亲自看到因果，逐渐修正对洞天的理解。 |
| 角色与环境承载叙事 | 敌人的避险、召唤物的旧礼、灵脉的流向和洞天意识的短句共同提供信息。完整见闻自动记录，战斗过程保持连贯。 |

战斗规则保持明白：遗物做什么、何时触发、危险落在哪里，都能直接理解。世界解释可以渐露：古人为什么造下这些东西，它们为何仍然运转，今日的传说究竟解释对了多少。

## 洞天的共同来历

### 玩家能够接触的故事

远古先民曾开辟洞天，令山川自养、群生各安其所。如今主事者不复现身，诸境灵脉相互阻隔，原本护生的异兽与守坛者也卷入反复到来的劫潮。

四种传承都保留了一部分与洞天相合的方法。行者镇山，羽客巡天，方士辨律，祝师归灵。人们对这些法门的来历各有解释，修士则在一次次入境中亲见它们的共同之处。

### 统一的隐藏因果

**以下为策划内部设定。** 洞天是远古文明建立的实体生态庇护与生命存续体系。文明利用一部分宇宙规律，使能量分配、环境调节、生命形态保存和守护机制共同运行；“道”所包含的规律仍大于这套文明能够掌握的范围。

诸境长期失联、局部受损，使原本相互协调的调节过程逐渐失配：局部供给过强，生灵异常增殖，守护者按残缺旧律清除异常，消散之力又回流灵脉，再次积聚。玩家吸收部分逸散灵蕴，能缓解局部失衡，也可能被守护者误判为新的异常。

灵脉、天劫、遗物与召唤共同指向这一套历史，避免每一件奇物都需要另起一份科幻解释。古老生命的情感、祭祀和守护誓言继续有意义；对形态与记忆的保存，也不足以直接回答“归来者是否仍是原来的生命”。

### 玩法与背景的对应

| 玩法现象 | 玩家看到的仙侠现实 | 隐藏层的统一解释 |
| --- | --- | --- |
| 选择地图 | 选择进入一处洞天 | 进入同一体系中职责不同的区域 |
| 自动攻击 | 本命之法随战意运转 | 传承保存了可自行展开的完整作用形式 |
| 波次敌潮 | 灵脉失序 劫潮复起 | 周期性的生态增殖与守护清除 |
| 经验升级 | 纳灵与悟法 | 吸收当地逸散供给，逐步展开更完整的法门 |
| 波后整备 | 劫息暂歇 凝神参悟 | 一轮回流结束后的平静时段 |
| 技能五级觉醒 | 法门圆融 | 同一道法形成更完整的作用形态 |
| 怪物掉落遗物 | 灵骸凝珍 古纹显形 | 生灵与守护者保留了可再利用的结构模式 |
| 通关后续战 | 平息一劫后选择续劫 | 局部得到缓解，洞天更深的循环仍在运行 |

击破失控守护者、吸纳逸散灵蕴后，本处洞天获得一段真实的稳定期，出口重新显现。通关为生灵争得喘息；选择续劫时，修士主动继续接引更深处的失衡。诸境失联的根因仍在，后续进入才会遭遇新的劫潮。

每波结束后进入安全整备：停止本波增援，关键精英或首领被击败、在场危险结束后，统一归集地面经验与已掉落遗珍，再处理成长和奖励。普通残敌退潮不视作击杀。进入整备后没有伤害和限时选择；玩家完成必要选择即可继续。

遗物拾取时化为道印，与本局灵息相合，立即产生能力；重复拾取强化已有印记。遗珍所显之印须借当前洞天的灵息运转，离境后印息散去，所悟形理仍在；人物保留法门图谱与见闻。这个解释对应已有的局外横向解锁：下一局可以有更多选择，基础数值重新开始。

## 玩法原则

- 操作集中在移动与遁术，常规技能自动攻击；遁术承担闪避、脱困和位置调整。

- 地图采用竞技场式洞天，以走位、聚怪、拾取经验和清除波次为主；观察异象、试用地形规律自然发生在战斗中。

- 波内经验积累为待处理悟法次数，每波结束后安全三选一，可连续处理多次升级。快速模式同样保留这一环节。

- 前两波给出方向遗珍，中段保障有效强化；关键成长后安排能展示清场能力的普通怪潮。

- 遗珍拾取后即时生效，同名正向叠层；阶段奖励在安全整备时选择，选择后立即生效。

- 局外保留道典、外观和内容解锁；本局等级、属性与遗珍叠层不带入下一局。

- 快速、传统和无尽共用战斗、技能与遗珍规则；普通通关先结算，再选择续劫。

## 核心循环与成长节奏

进局前选择角色、洞天和模式。波内以自动攻击清除敌潮，玩家移动、聚怪、拾取并使用遁术；经验持续累计为悟法次数，战斗不因升级弹出选择。每波结束后进入安全整备，完成技能成长与奖励处理，再开始下一波。

### 波后整备的固定顺序

1. 停止本波增援。普通残敌随退潮撤离，不视作击杀；关键精英或首领需要被击败，在场危险结束后才进入安全整备。

2. 归集地面经验与已经掉落的遗珍，保留掉落带来的收益；尚未击败的衔珍灵兽按逃离处理，不发放奖励。

3. 展示本波阶段奖励候选并完成选择，使玩家能依据新遗珍决定后续悟法。普通掉落已在拾取时生效。

4. 按累计悟法次数逐次三选一。只要存在未满级的已学技能，就保留至少一个已有技能升级候选；空槽允许新技能候选，六槽已满时仅提供有效升级。

5. 传统和无尽仅在指定阶段出现一次风险节点，明确影响下一波。完成所有必要选择后继续，不设倒计时。

同一次选择不重复摆放相同候选；不足三个有效候选时显示实际数量。角色固定被动、道象和遗珍不占用悟法候选。技能全部五级后，额外经验改为合并的本局修为成长，避免一波反复弹出无可升级的菜单。

选择的取舍来自升级机会和六个技能位置：继续提升主力以提前觉醒、学习新技能补足单体或生存、顺着早期遗珍发展，或保留空位等待另一方向。首轮不加入技能重置和装备整理。

### 关键成长后的清场时间

主力五级觉醒、道象成立或关键高阶遗珍到手之后，接下来的普通怪潮应能展示覆盖、清理速度或重点目标处理能力的变化。阶段首领后的下一波优先作为清场收获波，暂不叠加新的风险节点，也不随玩家变强同步提高所有普通怪生命。

普通关卡保持“建立方向、组合成型、享受清场、处理新压力”的节奏。后续挑战由精英配合、远程压制、冲锋和首领行为承担。前期低压仍要尽早提供第一次有效选择与方向奖励，避免长时间只有低变化的追逐。

快速十波样本在第五波安排阶段奖励，第六波展示新能力；第八波再次补强，第九波再给一次清场时间。普通通关的主要构筑奖励因此有实际使用窗口。

## 角色和共享技能规则

每个角色固定拥有一个专属起始攻击技能、一个核心被动和一种遁术特色。每局六个攻击技能槽，其中一个为固定起始技能，另外五个从二十项共享技能中选择。角色被动与遁术不占攻击槽，共享技能不按职业硬锁。

所有攻击技能最高五级。一级已经完整可用，二级和四级增强基础表现，三级出现明显改善，五级必定自动觉醒。觉醒不要求指定遗珍、另一项满级技能或隐藏配方；遗珍与道象用于放大或整理已成立的能力。

遁术是角色的闪避动作，共享短暂免伤和穿过敌人的基础能力。角色差异主要帮助脱困、调整位置或整理召唤物，常规移动仍有完整作用。遁术不承担必须反复使用才能维持的主要伤害。

本体技能指角色直接施放的非召唤攻击。召唤物日常攻击、遗物追加攻击、角色被动爆发单独处理。持续技能按自身的有效攻击轮次计算充能，同一轮的多个弹片、范围命中或余波不重复记作多次施放。

### 断岳行者

**神话身份：**守山一脉的行者，相信自身可以承接山河的震荡。刀锋将鸣时，脚边碎石总会先轻轻跃起。

**体验定位：**靠近怪群，连续挥斩，积势后以大范围斩击收割。

**专属起始技能 断岳三叠：**自动完成两次扇形斩击和一次较宽的终结横斩。

| 等级 | 变化 |
| --- | --- |
| 一级 | 自动完成两次扇形斩击和一次较宽的终结横斩。 |
| 三级 | 第三段附带短距离贯穿冲击波。 |
| 五级觉醒 | 第三段扩大为完整环斩，并保留前方冲击波。 |

**核心被动 镇劫势：**本体技能的有效攻击轮次命中后积势，满后自动进入短暂爆发：本体攻击加速，近身技能范围扩大。无需受伤或击杀，首领战也能积累。爆发期间暂停积累下一轮势。

**闪避特色 破阵步：**闪避落点震退附近普通敌人，提供落脚空间。

**优势：**近身怪群越集中，范围攻击越容易发挥。

**需要玩家处理的压力：**接近敌群时，远程交叉火力与连续冲撞要求保留脱身空间。

**角色短句：**“山未动，骨先鸣。退半步。”

### 巡星羽客

**神话身份：**背负残缺星图的巡天传人，在风向、流萤与山川走势中寻找旧日星路。他相信走对道路，便能借天势开弓。

**体验定位：**边移动边射击，将追击者拉成队列，以贯穿齐射清出通道。

**专属起始技能 贯星连珠：**自动朝目标进行短促连射，移动时持续攻击。

| 等级 | 变化 |
| --- | --- |
| 一级 | 自动朝目标进行短促连射，移动时持续攻击。 |
| 三级 | 每轮末箭获得贯穿。 |
| 五级觉醒 | 末箭变为贯穿扇形齐射，覆盖主要目标及两侧。 |

**核心被动 步罡蓄势：**普通移动积累星势，充满后下一轮贯星连珠自动追加强化贯穿射击。无需踩指定图形或手动瞄准；强化射击保留对主要目标的集中伤害。

**闪避特色 留羽：**闪避起点留下短暂羽影，牵制附近普通敌人，帮助改变移动方向。

**优势：**擅长持续远射、贯穿与移动中收割。

**需要玩家处理的压力：**近身保护较弱，四面出现的敌群需要先通过走位整理。

**角色短句：**“路已经断了，它们为何还往那里走？”

### 司霆方士

**神话身份：**研究雷息与灵候的方士，相信天劫有律。他会记录草木闭叶、地纹发亮和雷声到来的先后，以亲见修正师门旧说。

**体验定位：**多种法术持续铺开，合律后自动释放环身雷潮。

**专属起始技能 五雷引：**自动雷击主要目标，再向附近少量敌人传导；首目标保留足够基础伤害。

| --- | --- |
| 一级 | 自动雷击主要目标，再向附近少量敌人传导；首目标保留足够基础伤害。 |
| 三级 | 增加传导目标。 |
| 五级觉醒 | 首次命中位置追加一次雷爆。 |

**核心被动 雷律共鸣：**本体攻击技能完成有效施放时积累雷息，满后自动向周围释放雷潮。每个技能的一轮最多计一次；召唤物日常攻击、遗物追加效果和雷潮自身不再积能。任何兼容本体攻击都能积累，搭配不被限定为纯雷系。

**闪避特色 踏霜：**闪避落点留下短暂霜雾，减缓身边普通敌人，帮助重新建立输出位置。

**优势：**擅长区域覆盖、集中清群与周期爆发。

**需要玩家处理的压力：**施法有节奏，高速敌人可能在两轮攻击之间突入。

**角色短句：**“无人立足之处，也会落下这道雷。”

### 归灵祝师

**神话身份：**携灯为失散之灵寻归处的祝师。他相信洞天会记住众生，借陶俑、灵兽与古老道纹，让散去的行止再现。

**体验定位：**带领自动作战的小军团推进，持续战斗后唤出短暂魂潮。

**专属起始技能 陶俑卫：**两名披残甲的陶卫跟随角色、自动攻击；被击散后自动重聚。

| 等级 | 变化 |
| --- | --- |
| 一级 | 两名陶卫跟随角色、自动攻击；被击散后自动重聚。 |
| 三级 | 增加一名陶卫。 |
| 五级觉醒 | 陶卫周期性攻击改为横扫，增强军团清群能力。 |

**核心被动 众生回响：**附近敌人死亡积累魂息，陶卫持续命中精英与首领也能补充；满后唤出一批短暂游魂自动扑击。魂息获得速率与游魂同时存在数都有上限，再次触发优先补充或强化现有游魂。

**闪避特色 归灯：**闪避后召唤物迅速向新位置靠拢，再自动选择目标；已发出的远程攻击继续完成。

**优势：**擅长用追击、远射和近身支援分工建立持续火力。

**需要玩家处理的压力：**输出跟随军团位置，突然从侧后方出现的敌人会威胁本体。

**角色短句：**“我只唤你来战，何曾教过你这一礼？”

### 四种观察洞天的方式

| 角色 | 战斗中可以亲见的联系 | 可逐渐形成的理解 |

这些证据对所有角色可见，角色差异体现在关注点与短句。礼仪性驻足放在波间安全时段，战斗召唤物的输出与归队不因此中断。关键线索可以从地图和敌人中再次遇到，不要求轮刷四角色或等待指定传说。

策划层分别用共振导能、空间巡行、失衡调节和形态存续解释四门传承；它们同出一个体系，因此共享技能始终可以跨角色搭配。

### 道象计数和激活

道象由携带两门不同的合格攻击技能达成，满足后自动激活，不占攻击槽，不进入悟法候选，不消耗资源，也不新增道象等级。首轮不设置四门档。

一门已装备技能对同一道象最多计一次。等级、弹体数量、命中次数和召唤单位数量均不增加门数；觉醒仍然是原技能。角色被动、遁术附效、遗珍及其追加攻击不计入。多个标签不会让一门技能独自满足两门要求。

星罗有七门候选，含羽客起始技能与六门共享技能；万灵同息有五门候选，含祝师起始技能与四门共享技能。其他角色也可用共享技能达成，不按角色名称锁定。

### 星罗

**达成条件：**携带两门不同的本体投射攻击技能。

**玩家描述：**周期性使下一轮本体投射技能的弹体变宽，更容易覆盖敌群。

激活后获得一次待用强化，由下一轮最先发动的合格本体投射技能消耗；消耗后经过固定战斗时间重新获得，最多储存一次。强化该轮技能的原有弹体，包含觉醒增加的原生弹体，只增加命中宽度，不增加弹体数量，也不改变贯穿、弹射、追踪与爆炸规则。

召唤物射出的弹体、遗珍追加弹体和角色被动追加攻击，不消耗也不获得星罗的这次独立强化。整轮仍计一次正常施放，遗珍触发规则保持原样。

### 万灵同息

**达成条件：**携带两门不同的技能召唤攻击。

**玩家描述：**技能召唤物周期性进入同息，短时间内攻击更快、归队更迅速。

激活后在接下来的战斗中进入首次同息，随后按固定战斗时间间隔发动。同息提高技能召唤物的正常攻击节奏和归队速度，灵狼继续追击、幽鸦继续往返、神机弩继续射击与迁移、石卫继续随行重击。

它不立刻补发攻击，不重置攻击冷却，不复制单位，也不添加伤害标记。增益幅度不随召唤物数量叠加；加快后的正常攻击仍遵守遗珍原有的触发间隔和整队计数上限。伴魂灯伴魂、归灵幡魂影、黄泉符节灵骑与角色被动游魂均不受该道象强化。

普通跟随、归队和重聚始终是基础能力，同息只提高效率。两条道象仅按战斗时间运行，波间冻结计时与剩余持续时间；已储存的星罗保留，进入整备不会刷新次数或重启同息。

## 二十八件遗珍

遗物在世界中统称遗珍。普通掉落走近拾取后化为道印并即时生效，不占攻击技能槽，不需要装备或替换。品质分为普通、稀有、史诗、传说四档；同名叠层上限暂定依次为 5、3、3、2 层。首次获得提供基础效果或机制，重复获得主要增强已有机制的参数。

遗珍的适配依据是当局攻击方式，不按角色名称硬锁。行者携带灵狼后可以获得召唤遗珍；方士携带飞刃后可以获得投射物遗珍。陶俑、灵狼、幽鸦、神机弩与石卫统一按技能召唤物处理，外形不同不改变兼容标签。

## 三处洞天竞技场

首批地图提案各围绕一个核心规律展开。先深化栖雷古坛，可以同时验证波次节奏、角色差异、遗物成长和认知奖励；另外两处提供后续变化。地图主体保持开阔，异象改变走位和引怪的方式。

### 栖雷古坛

山巅古坛由断碑、雷击木与铜铃环绕。**核心规律是地纹先亮，经过三段明灭与低鸣后，雷击沿亮纹降下。** 位置随当局连接状态变化，顺序始终可信；视觉与声音共同预告，安全通路保持可达。

- 初见时，玩家学会离开亮起的雷纹。

- 再遇时，把追兵引入将落雷的位置，自己闪出，看到敌人同样受到伤害。

- 后来发现空地也会落雷，守坛者同样畏雷；断碑后面的纹路始终无法接续发亮。

这条规则先教躲避，再提供清怪手段，最后让“天雷察罪”的旧说出现疑问。首领受到环境雷击后出现短暂破绽，但基础技能始终可以完成击杀。各类目标受到的具体伤害与抗性按明确战斗规则处理，适用对象不因剧情临时改变。

### 回春玉圃

巨树根系围起古老药圃，玉枝与花床分布在开阔战场边缘。**核心规律是主根先亮，光沿根系传向花床，花苞开启后才出现新敌群。** 随机改变主根方位、花床组合和敌群配比，传递次序保持不变。

- 初见时，玩家看到某侧花苞先开，随后那边出现敌人。

- 再遇时，根光转向另一侧，玩家提前移动，让自动范围技能覆盖新来敌群。

- 后来发现这一类护圃白鹿每次“新生”都带着相同断角，特定复长枝条也重复相同缺损。

首领护圃树母的增援沿用主根预告。首领倒下，边缘花床仍在安全的波间时段轻轻开合，暗示回春有更深的来源。玉圃仍有自然繁衍的生灵，重复旧伤的现象先集中在特定护圃种群。隐藏层涉及生态重建与旧形态的保存；玩家可以先理解为仙圃复生，再追问为何连伤痕也被留下。

### 归声石窟

环壁残像、铜磬与陶石偶围成一座祭祀斗场。**核心规律是留影、显影、重演：石像保存战场上刚出现过的一种动作，先显出固定轨迹，再按该轨迹复现。**

首批重演范围限定在少量已教学的攻击动作，例如直线冲锋、扇形挥击和环形震荡。重演使用自身明确的伤害规则，不复制玩家完整构筑、遗物触发链或永久属性；轨迹锁定后不突然追踪玩家。

- 初见时，石偶使出刚刚见过的精英冲锋。

- 再遇时，淡色影迹先标出路线，玩家把追兵带入重演区域，自己避开。

- 后来发现不同石像能重演同一动作，破损石像依然严格完成同一个停顿与转身。

环境重演对玩家和敌人都能产生伤害，并有同时存在数量上限；第一次教学便展示它能击中怪物。影迹本身不算可击杀、可掉宝的生物，也不会成为再次留影的来源。首领守藏石君组合此前学过的少量动作，每次保留原本预告。玩家可以从招式回响联想到伴魂与陶卫，进一步思考洞天究竟保存了什么。

环境雷击和重演击杀的怪物照常产生经验并保留原有掉落判定。环境伤害不记为玩家施法、命中或遗物击杀触发；附近死亡类被动仍按其已有速率上限结算。

### 地图生态与奖励倾向

每处洞天由普通敌潮、少量关键敌人和稳定环境规律共同形成战斗倾向。奖励以共同内容池为基础，地图倾向只在已经适配且未满层的候选中调整相对出现机会；四名角色都能在每张地图完成基本构筑。

| 洞天 | 敌群与走位倾向 | 奖励和发现倾向 |
| --- | --- | --- |
| 栖雷古坛 | 追击、厚皮与少量远射，鼓励整理队列并借雷处理重点目标 | 更容易遇到与雷纹、控场、贯穿有关的适配遗珍；没有本体雷技能时不投放雷系专属奖励 |
| 回春玉圃 | 增援从主根指向的花床进入，夹杂快速突进，鼓励提前覆盖和及时换位 | 倾向持续覆盖、护体与召唤协同，线索围绕护圃种群的重复形态 |
| 归声石窟 | 少量明确冲锋、扇击与环境重演，鼓励读轨迹、留出转向空间 | 倾向往返攻击、军团协调与生存补强，线索围绕动作与记忆留存 |

本版核心技能和关键遗珍都可从共同池获得，地图不独占某条基础流派的必需物品。后续专属发现可以提供新表现与背景线索，仍保留其他地图的完整成长路径。

## 怪物行为与隐性叙事

普通怪持续提供可清除的敌潮；少量关键敌人承担不同走位压力与背景证据，首领组合已经出现过的规则。

| 敌人来源 | 战斗职责 | 背景线索 |
| --- | --- | --- |
| 劫变生灵 | 大量追击与少量突进，供玩家聚怪和清场 | 出现方向响应根光或灵脉流向，显示它们并非毫无来由地涌现 |
| 失律守卫 | 厚皮、远射或封路，迫使玩家调整路线 | 仍绕开雷纹，仍沿旧星路巡行，却把修士视为应清除之物 |
| 归藏残响 | 用少量清晰招式改变局部压力 | 反复做出同一旧动作，与陶卫、伴魂或壁上残像互相印证 |

精英身上的纹样与可能掉落的遗物相呼应，先让玩家见到一种力量，再得到使用它的机会。首件方向遗物仍在前两波给出；具体效果随机，不强迫每局重复同一流派。

洞天意识、残碑旧言与人物短句只表达其所在位置和职责能够知道的事。例如古坛守灵反复说“归流未竟，诸形勿越”，玩家可以先把它听成禁令，之后通过灵脉流向理解“归流”的含义。环境与角色行为保持有因可循，文本不凭空替玩家宣布真相。

### 衔珍灵兽

衔珍灵兽是携带遗珍、会逃跑的额外目标。只在有完整追逐窗口的普通波出现，不与首领波重叠，也不作为前期方向或中段成长的必需来源。身影、灵光和逃离方向可辨认，路径保持在正常战场内，所有角色都能依靠基础移动追逐。

灵兽远离角色时不吸走常规攻击。玩家主动靠近到明确的追击距离后，能够重新选取单体目标的自动技能优先攻击它；固定方向攻击、范围法术和正在完成的召唤攻击保持原有规则。追上后仍通过自动攻击击败，无需新按钮或手动瞄准。

击败后掉落一件稀有及以上的有效遗珍，对应候选耗尽时按奖励补位规则处理。逃走不扣资源、不阻止下一波，也不削减正常经验与保障奖励。波后归集只收取已经掉落的物品，不把逃走视为击杀。

灵兽会避开已经预告的雷纹或其他危险，给玩家额外的观察线索。追逐会改变路线，但环境预告与安全通路保持可信。

## 认知奖励与可误读的世界

道典自动保存玩家实际见过的遗珍、已激活的道象与亲自经历的异象。遗珍进入可辨认的掉落视野或奖励候选时即可记录已见名称与已展示效果；未拾取、未选择的遗珍不会因此生效。死亡仍保留发现记录，不把拾取失败变成自动获得战斗奖励。

| 记录类型 | 栖雷古坛的示例 | 对玩家的作用 |
| --- | --- | --- |
| 亲见 | 地纹先亮，雷霆后至；妖物也会受雷击 | 保存可以重复验证的现象 |
| 传闻 | 天君以雷察罪 | 保留当地人理解世界的方式 |
| 推测 | 雷霆似乎循着地纹，而非追着生灵 | 给出可继续验证的方向，仍用仙侠语言表述 |

每张地图先安排一个核心规律、三条关键观察和一个仍未回答的问题。基础通关、四名角色与核心战斗功能不要求解出隐谜。认知带来更早预判、更有效的引怪、变化的角色回应，以及见闻插图或外观奖励；新技能和遗珍的横向解锁始终有正常战斗挑战路径。

误读发生在现象的意义上：玩家可以把守卫当作忠于天君，把旧礼当作先祖归来。危险范围、落雷时序、伤害对象和遗物效果保持可信。后续证据修正解释，不反悔已教学的战斗规则。

## 随机演化与三种模式

不确定性来自玩家尚未理解的规律，以及本局状态的组合。已经验证的因果可以用于预测下一次；后续证据可以拓宽理解。

洞天每局改变初始状态：哪些灵脉连通、哪侧主根活跃、哪些石像留影、哪类敌人更多。环境规则保持一致。改变状态时先给可观察的征兆，避免无前兆地推翻玩家已经验证的规律。

| 模式 | 战斗与成长结构 | 事件选择与叙事 |
| --- | --- | --- |
| 快速模式 | 首轮采用十波约 8—12 分钟有效战斗作为候选节奏；前两波建立方向，中段强化，后段展示成型。 | 保留每波技能整备，省略阶段路线选择；一局完成一个小型认知转折。 |
| 传统模式 | 开始即可选择；留出更充分的组合完善、补短板和清场阶段。具体总时长与波数在短流程验证后确定。 | 每隔若干波出现一次风险节点；同一世界规律在不同条件下反复出现。 |
| 独立无尽 | 通关一次传统模式后开放；从基础角色进入，不沿用上一局强度。 | 阶段首领暂以每五波一次为候选，配合少量风险节点与已知异象，具体间隔待校准。 |
| 通关续劫 | 快速或传统通关后，继续使用本局构筑挑战更深劫潮。 | 已达成的通关与解锁立即保留；后续失败不撤回成果。 |

有效战斗时长只计算敌潮与首领战，安全整备、阅读和主动暂停计入总游玩时长并单独观察。独立无尽的入口解锁与普通通关后的续劫分别处理；快速通关可直接续劫，独立入口仍按传统通关条件开放。两种无尽起点的波数纪录分开保存。传统模式主要通过增加阶段和成型体验延长一局，避免仅拉长单波、推迟早期技能选择。

无尽压力优先来自敌群配合、精英职责和已有异象的组合。环境危险数量与频率有上限，预告和可达安全空间继续保留，普通敌潮仍提供清场满足感。关键叙事线索在合理长度的游玩中即可遇到；更深无尽重组已知规律，不把重要真相藏在极长存活要求之后。

### 阶段风险抉择

传统与无尽每阶段最多提供一次节点选择，快速模式省略。节点放在一段能力兑现之后：例如阶段首领奖励、清场收获波，随后再为下一波选择风险。首轮每次节点只影响下一波，结算后解除，不无说明地连续累积。

| 节点 | 下一波变化 | 奖励 |
| --- | --- | --- |
| 稳境 | 常规敌群与环境压力 | 稳定的基础经验与掉落 |
| 迎战守境者 | 增加一名能力已经介绍过的精英 | 击败后获得一份适配遗珍奖励 |
| 接引灵潮 | 普通敌群更密集，仍保留正常预告和安全通路 | 更多当局经验成长，额外高品质掉落仍遵守波段边界 |

选项明确显示敌人变化、环境变化、奖励与持续范围。玩家的取舍是这波想承担何种压力、获得何种成长；不设选择倒计时。技能悟法与阶段节点分别处理，不把一次节点选择等同于一次技能升级。

### 难度挑战词缀

难度词缀在基础循环验证后加入，用于自愿提高一整局的挑战；与仅影响下一波的节点分开显示。先验证少量清楚的变化，例如特定精英组合增多、异象更频繁但保留完整预告、首领组合已教学的招式。

基础难度可以获得全部核心内容。挑战奖励提高明确的适配奖励机会或高品质权重，不突破遗珍兼容与叠层规则。更多普通怪同时增加经验，不能直接按敌人数给未经验证的风险分；奖励质量与经验收益一起校准。

首轮保留个人通关与波数记录，不将在线排名作为玩法验证前提。独立无尽与通关续劫分开记录，后续比较成绩时还需区分地图和挑战条件。

## 首次游玩的十波体验

以下采用断岳行者或归灵祝师进入栖雷古坛的十波快速局，候选预算合计约 8 分 20 秒至 11 分 15 秒有效战斗，另计整备时间。预算用于设计节奏，不是超时判负或强制结束首领的倒计时；首领战会随构筑与操作浮动。每波可处理多次悟法，成长总量与候选应支持专注升级的主力技能在中段觉醒，分散投资也可通过多技能与道象形成有效组合。

| 波次与候选预算 | 主要战斗和成长 | 环境线索与能力兑现 |
| --- | --- | --- |
| 1  30—40 秒 | 低压追兵，体验起始攻击和移动；波后首次选择共享技能。 | 断碑微光与铜铃轻鸣出现，危险尚未叠加。 |
| 2  40—50 秒 | 入门精英出现，击败后获得一件通用稀有方向遗珍。 | 精英道纹与掉落相呼应；掉落立即生效，波后继续悟法。 |
| 3  40—50 秒 | 小规模混合敌群，首次介绍完整环境雷击。 | 地纹亮起，三段明灭与低鸣之后落雷；安全空间充足。 |
| 4  45—60 秒 | 密集低生命敌潮，让早期组合兑现清场能力；可偶遇衔珍灵兽。 | 追兵也会受雷击；追逐目标沿正常战场活动，忽略它不影响基础奖励。 |
| 5  60—80 秒 | 阶段首领使用此前学过的动作；战后给出史诗为主的适配三选一。 | 完成这一节点可得到有效强化；候选不足按奖励补位规则处理。 |
| 6  45—60 秒 | 主力觉醒或多技能方向进入展示阶段，安排一整波可高效清除的普通敌潮。 | 不同时提高全部普通怪生命；玩家借雷清怪后可触发一句短评。 |
| 7  55—70 秒 | 加入少量冲锋与远程配合，检验位置与生存短板。 | 环境预告完整保留，断碑后的纹路始终黯淡。 |
| 8  60—80 秒 | 第二次精英奖励，允许完善已有方向或补足短板。 | 精英也会回避亮纹，空地照常落雷。 |
| 9  50—65 秒 | 再次安排大型普通怪潮，让后段奖励也有使用窗口。 | 成型构筑可以主动利用雷路，也能靠技能完成清场。 |
| 10  75—120 秒 | 最终守坛首领；击败后先结算成功，再选择离境或续劫。 | 首领受到环境雷击时出现短暂破绽；战斗遗珍奖励供续劫使用。 |

行者可用断岳三叠与回风刃环建立近身清场，也可选择穿云重矢和雷火符矢转向本体投射。祝师可用陶俑卫与裂牙灵狼形成技能召唤组合，再补寒潮诀或归墟印。两名角色都能进入两条试验道象；首件方向遗珍改变后续选择的吸引力，而非指定唯一配方。

战后见闻自动记下亲见事实：雷纹先亮而雷霆后至；妖物和守坛者也会受雷击；空无一人的亮纹照样落雷。旁边保留当地旧说“天君以雷察罪”。玩家可以自行发现两者之间的张力，无须弹窗公布标准解释。

## 掉落与触发规则

### 拾取保持正向

默认遗物不扣除生命上限、不禁用闪避、不删除原技能，也不消耗已有召唤物。额外投射物、魂影和爆发都在原有能力上增加作用。

同名遗珍重复直接叠层，达到上限后移出本局有效候选；已生成但尚未拾取的同名物品若在之后达到上限，拾取时按满层补偿规则转为有效收益。极长无尽中，技能与遗珍池逐渐耗尽后，奖励转为明确的本局通用强化，具体规则见后文。

### 奖励适配与方向开放

四件稀有方向遗珍从一开始就可获得。后续史诗与传说按已有技能匹配：没有兼容本体投射物时不掉穿云扣，没有本体雷电技能时不掉雷庭圣印，没有技能召唤时不掉归灵幡。品质提升、地图倾向和难度加成都不能越过适配与未满层检查。

伴魂灯提供基础召唤体验，可以引导下一次选择召唤技能；仅有伴魂灯时，依赖正常召唤物触发的遗物暂不进入候选。通用伤害、范围和持续攻击奖励仍然有效。

新增解锁扩大可选内容，但每次悟法只要仍有可升级的已学技能，就保留至少一个对应升级候选。未满六槽时可以同时提供新技能；满槽后不继续投放无法学习的新技能。被动、遗珍和道象不混入本版攻击技能升级池。

### 本局奖励保障与来源

| 来源 | 兑现内容 | 与其他奖励的关系 |
| --- | --- | --- |
| 前两波方向节点 | 一件通用稀有方向遗珍，四种机制之一立即可用 | 额外掉落不会取消该节点；已有同名仍可有效叠层，满层则换有效候选 |
| 普通精英 | 击败后保证一份稀有及以上的适配奖励 | 无可用高品质物品时按补位规则提供真实有效收益 |
| 中段阶段首领 | 一次史诗为主的奖励选择；存在可用史诗或传说时，至少一个候选来自这两档 | 先按当前技能与叠层生成候选，再选择；不要求取得指定传说 |
| 普通怪与衔珍灵兽 | 前者承载额外惊喜，后者提供追逐成功的适配奖励 | 均不挤占方向保障与阶段首领奖励 |
| 最终首领 | 成功记录、已经达成的横向成果；续劫时领取当局战斗奖励 | 普通离境不携出强度，续劫失败不撤回已结算成功 |

保障指玩家获得有效选择机会。玩家主动选取另一项收益后，该机会正常结算，不因未选最高品质反复补发。额外掉落可能改变节点中的有效候选，但不删除节点。

普通怪的额外高品质机会按计划战斗时长与波段安排，每波有有限机会边界；仍由击杀和实际掉落呈现。敌人更多可以提供更多经验，但不会自动使高品质抽取次数按怪物数量等比例增长。难度提高品质权重时，连同这部分经验收益一起校准。

各模式分别观察首次方向奖励、中段有效强化及其剩余使用时间，不使用统一的“几局一次史诗或传说”作为本版目标。传说属于额外高潮，基础成型由技能、稀有方向与史诗强化共同支撑。

### 奖励选择与候选不足

阶段奖励最多展示三个不同候选。先抽取已解锁、适配当前技能、尚未满层的史诗；传说按该来源的额外品质机会加入。池不足时，依次用可立即生效的稀有或普通遗珍、本局通用奖励补位，并显示真实品质。

最终只有一至两个有效候选时，就显示一至两个；不重复同名凑数，不用无效奖励填位。最低要求是每次选择能实际增加能力、恢复缺失生命或补充未满护盾。

击败最终首领后先结算成功，再让玩家决定离境或续劫。选择续劫后领取战斗奖励，在下一段敌潮中使用；正常离境保留已经获得的道典记录、外观与横向解锁成果。

### 满级与满层后的本局收益

| 通用收益 | 作用 | 有效条件 |
| --- | --- | --- |
| 修为 | 小幅提高攻击伤害，沿用同一个通用伤害加成项累加 | 可持续提供当局收益，每次奖励不另开相乘倍率 |
| 疗愈 | 立即恢复实际缺失生命 | 生命已满时不进入候选 |
| 护体 | 补充临时护盾 | 受既定上限约束，护盾已满时不进入候选 |

技能全满后的经验在波后合并为修为收益，不再重复选择满级技能。遗珍同名满层后退出后续候选；已经生成的满层同名掉落，以及无有效遗珍可选的奖励，转为上述通用收益。普通自动拾取补偿优先使用修为，选择型奖励可提供当前有效的疗愈与护体。

这些收益均只在本局存在。无尽中的奖励频率仍受波段和节点约束，敌人压力继续提高；持续成长不保证无限存活。

### 附加效果与持续攻击

本体攻击和正常召唤技能的攻击可以触发对应遗物。遗物产生的爆炸、追踪光矢、伴生幽魂、魂影和骑兵可以造成伤害、击杀并获得经验，也可以享受适用的基础增益，但默认不再为其他遗物提供触发计数。

一轮齐射、斩击、余震或多段法术仍算一次施放。累计命中型效果对持续区域、环绕攻击和召唤群采用明确的短时间计数上限；每件遗物还保留自己的触发间隔。技能觉醒产生的追加攻击不能再次生成同来源的追加攻击。

行者的镇劫势与方士的雷律共鸣只接受本体正常攻击轮次。祝师魂息可接受附近敌人死亡，但按固定回复速率限制，游魂同时存在数也有上限；陶卫持续命中精英或首领提供独立的基础魂息来源。

### 单体与生存

每名角色的起始技能都承担基本单体战斗。行者靠命中积势，羽客强化贯穿对主目标仍有效，五雷引保留首目标伤害，陶卫依靠持续攻击获取魂息。“五雷”是法门称谓，实际连锁数量按技能等级明确说明。

回风镖可以折返命中孤立目标；牵引和寒霜对免控目标保留伤害；召唤物能持续追击单体；汲魂镰无需击杀就可回血，但一次施放的回复量有限。

荆棘护体自动攻击且自然到期也能爆发，避免要求故意受伤。疾风回响的基础攻击独立于闪避，避免让脱困技能成为必须卡冷却使用的伤害按钮。

## 首次进入与横向解锁

建议四名角色在首发体验中均可选择。首次进入时开放十二项共享技能：回风刃环、开山横斩、穿云重矢、雷火符矢、流火雨、寒潮诀、裂牙灵狼、神机弩、归墟印、荆棘护体、疾风回响、汲魂镰。另八项通过正常游玩横向解锁。

首次进入的遗珍池包含 8 件普通、4 件稀有方向、4 件史诗强化和 4 件传说，共 20 件。初始史诗为断军印、并蒂箭珏、引雷玉、协猎骨笛；初始传说为裂阵战旗、天弦冠、雷庭圣印、归灵幡。其余 8 件通过正常战斗挑战解锁，初始池已经支持四种角色的关键方向。

解锁围绕首次体验和完成挑战，例如用某类技能击败阶段首领、首次通过不同地图、尝试新的攻击组合。快速与传统都提供合理进度。局外不增加永久伤害、生命或背包容量；失败保留已经达成的发现与解锁条件。

三种模式沿用相同技能、道象、遗珍和触发规则。四名角色均可在完整首发内容中选择；首轮原型先抽取两名进行验证，原型缩小范围不改变首发四角色目标。

## 后续扩展原型与玩法验证

以下保留原先较大的原型与检查方案，供核心循环成立后按需取用。当前先完成[首个玩法原型](first-playable-prototype.md)中的三波体验。

### 备选内容范围

后续可抽取一张地图、两名角色、十项技能和十五件遗珍，验证快速模式的完整体验。完整内容规划为四角色、二十四技能、二十八遗珍与三处洞天。

| 四件稀有遗珍 | 劫烬印、追猎银铃、凝霜髓、伴魂灯 |

原型池是用于验证的固定内容切片，不复制正式版的全部初始解锁条件。两角色均可选穿云重矢与雷火符矢达成星罗，选裂牙灵狼与神机弩达成万灵同息；祝师还可用起始陶俑卫更早满足召唤条件。

十技能切片内只有两项本体投射候选，因此星罗暂时表现为固定的二技能组合。首轮可验证联动反馈与取舍，完整投射方向的替代选择要在加入回旋飞钺、回风镖、追魂飞刃与疾风回响后继续验证。

传说维持随机惊喜，验证时需专门覆盖它在中段出现后的一段完整战斗，观察是否兑现预期。首次试玩需要覆盖衔珍灵兽可追与可放弃的情境；正式局不保证每次出现。

快速样本稳定后，再安排缩短但结构完整的传统流程，包含风险节点、下一波风险兑现、阶段首领奖励及随后的收获波。之后扩展羽客、方士与其他洞天；快速模式的结果不代替这些内容的验证。

### 验证记录

| 观察项 | 记录方式与用途 |
| --- | --- |
| 开局成长 | 记录首次有效选择、首次方向遗珍和首次明显强化的时间，判断是否等待过久 |
| 选择意义 | 同时记录候选出现、玩家选择、当前技能与剩余槽位；区分经常出现和真正愿意选 |
| 成型兑现 | 记录关键奖励后至少一波的清场表现，以及玩家能否说出变化来源 |
| 整备负担 | 记录每波选择次数、整备时间与犹豫原因，检查是否堆积过多阅读 |
| 单体与生存 | 分别观察两角色在少杂兵首领战中的持续输出、资源积累与脱困能力 |
| 道象与混合组合 | 检查每门计数是否容易理解；保留控制、生存技能的组合是否仍有竞争力 |
| 环境认知 | 记录玩家何时开始主动利用雷纹，第二次遇到规律是否处理得更好 |
| 额外追逐 | 记录追逐、放弃和失败原因，确认目标有吸引力且未挤压基础成长 |
| 再开动机 | 记录是否愿意再试，以及想更换什么；区分新组合期待与被迫补刷的感受 |

选择率以实际出现次数为分母，同时解释竞争候选和当时构筑。平均存活时长、通关与再开意愿共同观察，不凭单一指标或未经验证的百分比宣布玩法成立。

### 角色与构筑检查

首轮用差异明显的断岳行者与归灵祝师，验证起始技能、移动方式和自动攻击能否形成不同体验。两者在无指定稀有遗珍时仍应完成基本波次与单体战斗；后续再用相同方法验证羽客与方士。

关键成长后必须能观察到收益：清怪更快、覆盖更广或高威胁敌人更容易处理。波次安排要在首领终局前提供兑现窗口；前期方向奖励至少支持两种有吸引力的后续选择。

召唤物能够自动归队和重聚，功能攻击不要求故意挨打或额外操作，遗物不会因触发顺序取消已有能力。忽略全部背景文本仍应能够识别危险、理解奖励并通关；愿意观察的玩家则能通过同一规律改善走位，并提出有证据的世界解释。

### 背景与战斗需要一起验证的内容

- 不了解背景的玩家能否凭预告躲开第一次异象，并说清遗物的即时作用。

- 第二次或第三次遇到相同规律时，玩家能否主动借它改善走位或清怪。

- 玩家能否指出至少两项相互印证的证据，而非只凭一段解释接受世界真相。

- 神话短句、法术效果和地景异象是否保持相同的因果，是否遮住了关键敌人预告。

- 不同角色是否都能获得核心线索；未掉指定稀有遗物时，是否仍能自然看见对应证据。

- 波间的礼仪、短句和见闻是否保持可略过，且不延迟下一波或增加重复阅读负担。

## 后续扩充边界

随机灵纹先保留为独立的小范围试验，不进入首轮核心规则。例如劫烬印首次获得时随机确定广焰或烈焰：前者扩大爆炸覆盖，后者增强爆炸伤害；后续同名只按既定上限增强本局已定变体，不反复重掷。这个试验用于判断掉落变化是否增加期待，之后才决定是否扩展。

额外技能联动与隐藏配方可提供新形态，五级必定觉醒继续成立。发现后，道典明确记录触发条件；不以隐藏配方补回基础技能缺失的强度。真正的双技能合成还需单独明确技能消耗、空槽释放和原有控制能力的保留，暂不加入本版。

六件装备槽、随机多词缀、背包、补给点鉴定和互斥装备机制，作为另一种偏装备管理的体验方向保留。永久属性、背包扩格不属于当前纯横向规则。当前成长的取舍由六技能槽、升级机会、阶段奖励与风险节点承担。
