## 版本说明

仓库原有文档与本次补充的两份 v0.1 原稿，属于不同整理版本，内容范围和部分规则存在差异。本次仅补充原稿与目录，尚未将各版本合并为统一的实现规格。

两份 v0.1 原稿保留原始文字、数值、Markdown 格式与待定事项，仅以便于阅读的文件名和 `.md` 扩展名存放。
