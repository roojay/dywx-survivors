## 版本说明

仓库原有文档与本次补充的两份 v0.1 原稿，属于不同整理版本，内容范围和部分规则存在差异。两份 v0.1 原稿归档时仅补充原稿与目录，历史归档时尚未将各版本合并为统一的实现规格。2026-10-31 本次用户授权已以配套玩法 v0.1 与参数表作为 MVP 实施基线，具体默认决策见 `mvp/IMPLEMENTATION-SCOPE.md`。此次补充交接文档和美术参考，不改写既有玩法原稿。

两份 v0.1 原稿保留原始文字、数值、Markdown 格式与待定事项，仅以便于阅读的文件名和 `.md` 扩展名存放。
