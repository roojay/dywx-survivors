# 全功能需求差距审计（实施前基线）

日期：2026-10-30。基线提交：`c77483eb59985fc344879c59fd40e239ab053ef2`。
依据：`docs/gameplay-design-v0.1.md`（完整目标）与 `docs/mvp-prototype-config-v0.1.md`（具体原型规则/数字）；更早 `game-design.md` 不覆盖 v0.1。此文档是**基线审计，不是新增实现验收报告**，后续提交必须另填行为证据，不能因代码名称或字符串出现就标完成。

## 核心结论

基线有实质性的快速战斗、构筑、整理和道典核心，但尚不是全功能游戏。传统/无尽、分层系统、经济/机缘、传承/劫数和消耗式波间存档均缺闭环。不能再以“原型只做第一层”豁免这些需求。三洞天/三修士/30术法/约80法宝是建议内容量而非精确硬门槛，但金木水土、御兽符箓及每洞天独立生态等功能类别仍是完整设计覆盖范围。

状态：**有核心**指读到可执行逻辑，非UE验收通过；**部分**指现有子集；**缺失**指权威状态/命令/真实调用链尚不存在；**待实测**指不能用离线逻辑证明。

路径缩写：T=`Source/DywxUI/Public/MVP/Types.h`；P=`Source/DywxUI/Private/MVP/Progression.cpp`；S=`Source/DywxUI/Private/MVP/Simulation.cpp`；U=`Source/DywxUI/Private/SDywxRoot.cpp`；W=`Source/DywxUI/Private/MVP/DywxMVPWorld.cpp`。行号对应基线，不随新实现漂移更新。

## 建议数值/内容量，和真正刻意延后项

**建议可校准但不得沉默删除：** 快速8–12分钟/传统30–40分钟，4/10波及每波秒数；额外开匣5次、封存3次、重悟2次；总永久加成≤10%；3洞天/3修士/30术法/约80法宝；每修士≥3路线明确属后期内容扩充目标；仙品每约5局/道品每约15局、2–4件购买量、18–20顿悟、30–40%破境率均须批量或真人数据校准。数值改变应记录原因与实测，不得只写“可配置”就算满足。

**确实刻意延后，不是当前缺陷：** 本命法宝带出（首可玩版本明确局内限定，carryOut字段T已有）；移动端；联机（首发单机，只避免规则阻断）；线上排行榜不是明示基础设施要求（无尽存活波数本地排名可先交付）。

**文档内裁决：** v0.1配置对原型精确细节优先：火打雷盾×2；形态共鸣默认开启只是原型可切换实验，不覆盖完整分层规则；灵潮配置建议修为+20%与完整设计灵石更高可同时实现并明示；最终“奖励口径”公式优先于前文笼统击杀结算。波间存档“回到该波开头”需明确checkpoint索引，建议保存待迎战波的完整起始状态；不能恢复已经结算的波尾再领一次机缘/奖励。

## 模块分工与验收顺序

1. **共享契约先行：** mode、map、hero、system-tier、run-id、account、checkpoint、economy/intermission快照字段。所有runtime数组去除固定12/15/2等隐式假设或统一Count。
2. **账号/存档模块：** 传承/层级/阶梯/成绩/结算账本/单次消费slots；纯C++可测，UE仅文件adapter。不要让角色切换清空账号道典。
3. **局内经济模块：** 交易/机缘/待祭炼/封存跳过；命令返回成功与拒绝原因，复用Progression合法装备/派生属性。
4. **世界/模式模块：** 传统/无尽循环、异象/洞天/程序地图、劫数；结算事件只由权威状态机发出。
5. **内容模块：** 扩展数据与新行为、各洞天生态/机会池、道典；用内容表生成UI，不写第二套机制文本。
6. **集成/UE界面：** Nav→Controller→World→Simulation真实路径；菜单解锁/选择、经济交互、存读、机缘与异常反馈；新状态变化必须触发UI rebuild。
7. **离线行为验收：** 新号层1→快速胜利层2→传统胜利层3→无尽第5/10波洞主后继续；败局结算一次；跨修士恢复/消费slot；固定汇率/保底/商店/重铸/宝匣交易；seed地图连通；新增元素与形态真实伤害/目标选择。
8. **UE最终门禁：** build、cook、启动、完整三模式人工可玩、100+妖魔帧耗/GPU、不同分辨率/字号、存档真实磁盘与重启。当前环境缺UE，必须标 NOT_RUN，不能假称“满足所有功能且已验收”。

现有 `scripts/test-mvp-all.sh`明确输出离线通过且UE NOT_RUN；其中python contract脚本主要是源码/资源合同，不能证明新增按钮可达、Slate可编译或经济真正接上战斗。新增功能必须有直接状态断言/真实命令序列，而非只新增字符串断言。
