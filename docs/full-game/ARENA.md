# 洞天演化与六象运行契约

实现：`Public/MVP/Arena.h`、`Private/MVP/Arena.cpp`（无 UE 依赖）。

## 地图

默认有限地图为 96×54 格，与配套配置的约 3×3 屏相符。SplitMix64 是该模块自己的确定性随机源；不消耗战斗/掉落随机序列。不同洞天及种子生成不同障碍。中央半径 10 格预留空地；边界切角，外围保留闭合灵兽逃跑环线及刷怪点。路径每一段而非仅端点均检查障碍净空。外围灵脉与陷阱位置跟随种子重排。

障碍采用有限次数拒绝采样，障碍面积硬上限 25%。生成结束对带角色净空的网格执行四邻域 flood fill，要求全部可行走格连通；失败则退回无障碍安全布局。不存在无限重试或复杂导航框架。碰撞与渲染必须消费同一个 `ArenaLayout.obstacles`；不要再使用旧的固定六障碍。

`Contains` 使用同一个切角边界；`Constrain` 同时处理障碍和边界，最多八轮，极端失败回中央安全区。`beastRoute` 为闭合无终点的外围循环，AI 应逐路点前进；不可把末点当死路。出生保护沿用 RunConfig.spawnGrace（配套配置为 5 秒）。

`ArenaConfig` 所有新增平衡值均为可配置暂定值；输入经有限值检查与合理范围裁剪。可配置障碍数量、半径、尝试次数、中央净空、导航净空、网格与灵脉数。默认长宽来自配套配置，其他布局参数不是已定稿设计值。

## 三处洞天

`CaveCatalog()` 提供雷泽、赤山、青岚的名称、洞主称号、六职责妖魔名称、角色权重、色调提示、专属法宝子池与机缘池。新名称、权重、池配置均为暂定首发扩展示例，不声称这些嫁接名称逐字出自典籍。角色权重顺序是群行、冲锋、远程、自爆、护持、召唤，**不是 EnemyRole 枚举序号**。可选专属法宝池是原始目录 ID 子集，消费方应与完整内容目录校验/扩展，而不是排斥通用掉落。

## 六象

`Reset(seed, layout, layerTwo, config)`：第一层完全禁用；第二层按种子洗牌循环六象，保证全部可遇到。异象挂在布局灵脉上。`Step` 只接收战斗经过时间（波间/暂停不可调用）。预警事件不造成伤害；后续落点事件锁定原灵脉位置，不追踪玩家。单次异常 dt 最多推进 3600 秒，以限制事件内存；正常调用应使用 fixedStep。

- 雷泽引雷：预警后落雷；玩家在落点且已具雷象时 `absorbed=true`，不受这次雷伤，暂获雷象增伤。
- 灵潮涨落：增加刷怪与灵石收入，**不改变坊市或炼化汇率**。
- 地脉震荡：预警裂隙、冲锋权重增加；裂隙同时伤及妖魔，是可利用的回报。
- 灵雾：降低远眺可见范围、增加远程妖魔和灵兽；**不可降低术法射程或索敌范围**。
- 月蚀：夜行妖魔增伤、击杀修为提高。消费方须只给夜行生态角色加成。
- 阵台共鸣：站在固定阵台范围内提高玩家威力，离开立即失效。风险是固定驻足与妖潮围攻，而非额外玩家减益。

`Modifiers(player)` 只输出环境/敌人变化或正面玩家加成，不直接削弱任何道象。`State.encountered` 可用于点亮道典；名称与说明可在未解锁时灰列。完整数值须从 `Config()` 读取并在局内明示，不能把叙述说明当作数字配置。

新增数值全部在 `AnomalyConfig` 中可调，默认 24 秒轮换、16 秒生效、1.2 秒预警仅为暂定调试节奏，不是设计文档既定平衡。

## 集成检查

Simulation 要以同源布局替换旧 Clamp/Edge；消耗 hazard events 生成真实预警/伤害，并在刷怪、奖励、伤害结算与灵兽路径中消费 Modifiers。World 要显示相同障碍、切角边界、灵脉及异象；雾只遮蔽视觉。不应把独立模块测试通过等同于以上集成完成。

`bash scripts/test-mvp-arena.sh` 检查 1000 个种子的网格连通、面积、出生安全、碰撞修正、确定性与六象状态/收益/门槛。`SANITIZE=1` 启用 ASan+UBSan；工具环境 ptrace 下按现有约定关闭 LSan。
