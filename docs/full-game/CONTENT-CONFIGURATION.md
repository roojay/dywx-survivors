# 完整游戏内容配置与兼容协议

本次新增配置均为 **provisional（暂定、待实测校准）**，不是来自用户已确认的平衡数值。原火雷10门基础术法、2条破境与15件法宝的既有数值保留。配置与离线测试不替代 UE 编译、实机视觉/性能与玩家体验验收。

## 范围与稳定 ID

- 30 基础术法 + 6 破境成品；3 修士；11 心法（其中3专属）；80 法宝。
- 元素6种、形态5种。`None` 保留旧数值（Element=2、Form=3），新增枚举追加，数组由 `Count` 导出且包含 None 空槽。
- Spell旧0–11不变（10、11仍为旧融合）；新增基础12–31，御兽双术法融合32；新增心法融合33–35。必须用 `IsFusion` 分类，不可用“小于30”判断基础术法。
- Relic旧0–14不变，新增15–79；发现数组由 `kSpellCount/kPassiveCount/kRelicCount/kFusionCount/kResonanceCount` 导出。
- 旧存档应由版本迁移逐项导入旧前缀，不能将旧二进制布局直接解释为新数组。

## 激活和成长接口

`Reset(seed,hero,forms)` 保留旧原型候选池和随机序列，保证旧测试可重复；完整游戏调用 `ConfigureFullGame(layer,permanentBaseline,extraRerolls)`，再调用 `SetContentUnlocks(spells,relics)` 接上传承购买标志；未购买时保留原型候选（御兽起手及其配方另一半始终可用）。道典仍公开全部目录；购买术法池开放20新增基础和新增通用心法，购买法宝池开放65新增主题。

`permanentBaseline` 是应用永久加成后的基础 Stats（例如 power=1.1，而非0.1）；Derive 在此基础上叠加心法、装备与共鸣。调用方不得每帧重复叠永久加成。

- `SealOffer(index)`：第二层起可用，每局3次，术法/心法永久移出本局候选；不消耗本次顿悟，重新生成候选。
- `SkipUpgrade()`：第二层起可用，放弃当前一次顿悟，暂定固定返4修为、5灵石；原始修为不乘额外收益。`TakeSkipStones()` 原子领取后送 Economy，避免重复结算。
- 配方另一半已有5重时，对应候选权重×2；至少一次优先道象亲和抽取仍保留。
- `GenerateBossRewards(bossOrdinal)`：每个正序号只生成一次，支持无尽多洞主；旧无参接口保持原型单洞主幂等。
- `SetRelicPool(ids)`：共享旧0–14加当前洞天新增专属合法目录，其他洞天的新增专属法宝不能掉落；所有普通掉落、洞主奖励、坊市及宝匣共用此约束。`RealmRelicPool(int)` 返回完整专属子池。雷泽偏雷金水，赤山偏火土，青岚偏木御兽，剑阵符按逐件表分配；`SetDropRiskWeight` 仅增灵品以上权重，不增加总掉率，不保底道品。精英/灵兽的灵品为基准，仙/道权重受气运风险提高，避免所有非零权重同时相乘抵消。完整游戏仙品权重另乘 `1 + 0.1 × 未出仙品波数`（0–19波，暂定），第20波下一随机法宝必仙；旧MVP仍仅固定表与硬保底。`DropRarityProbabilities`/`DescribeDropOdds` 返回当前气运/劫数/软保底归一化后实际概率。

## 新增术法的可执行协议

`SpellConfig::behavior` 取 `Cone/Projectile/Field/Companion/Talisman`（旧术法为 Legacy）。不是纯展示名字：所有模板有明确damage、cooldown、radius及行为字段。Simulation负责消费这些字段；需逐个实效测试。

| 模板 | 行为 | 新门类 |
|---|---|---|
| Cone | 面向扇区近身命中，使用coneDegrees，5重180°并额外麻痹0.25秒 | 断金掌、青藤缠手、沧浪掌、镇岳拳 |
| Projectile | 飞行、穿透、元素命中；5重回旋 | 庚金穿云剑、青枝回生剑、寒潮飞剑、玄岩重剑 |
| Field | 按interval跳伤、持续duration；5重随身 | 金罡剑阵、青木生息阵、寒潭阵、地阙阵 |
| Companion | 灵兽跟随修士，在radius内索敌，每interval攻击；5重数量+1 | 赤羽灵禽、惊蛰灵貂、青鹿引灵、玄水灵龟 |
| Talisman | 优先最快威胁，0.35秒预警后范围伤害；5重数量+1 | 离火爆符、惊雷定符、金锋破符、镇山灵符 |

完整实数以 `ContentCatalog.cpp` 顶部 Row 表为唯一配置来源；`DescribeSpell` 同源显示。统一新增精进：2重基础威力×1.2；3重范围×1.2（飞行物再+1穿透）；4重冷却×.85（持续效果再+1秒）；5重模板质变。

额外字段 `slowFraction/slowDuration/healOnHit/shieldOnCast` 必须分别产生减速、回复与护盾，不得只描述。火模板附3/秒、3秒灼烧；雷模板一跳50%连锁。水命中需由模拟实现灭敌对地火、对灼烧目标互动奖励，不能引入元素免疫。

御兽修士起手青鹿引灵，专属御灵真经：生机+.3/秒、摄灵+1、御兽计数+1及御兽威力+10%。青鹿引灵5重+玄水灵龟5重→森罗玄武，保留木1、水1、御兽2全部计数，只占一槽。

## 全道象共鸣

原火/雷/法体/飞剑/阵法保持旧规则。新增效果集中由 Progression::Derive 执行；Simulation 不应再次加同一数值。新增第4门奖励叠加第2门。

| 道象 | 2门 | 4门额外 |
|---|---|---|
| 金 | 金伤+15% | 会心+10% |
| 木 | 生机+.5/秒 | 生机+.5/秒、木伤+20% |
| 水 | 水伤+15% | 周天+10% |
| 土 | 护体+8% | 气血+30、土伤+20% |
| 御兽 | 御兽伤+15% | 御兽伤+15%、生机+.8/秒 |
| 符箓 | 符箓伤+15% | 符箓伤+15%、范围+20% |

形态开关仍控制所有形态加成；六元素不依赖形态开关。共鸣码保留旧火雷法体飞剑阵法0–4，追加金木水土御兽符箓5–10。

## 80 法宝不是仅追加展示名

新增65件各有独立目录 ID、品阶和主题组合（主属性/道象/触发/玄机），由 GenerateRelicFromCatalog 真正生成并进入完整游戏掉落。测试校验新增主题元组唯一。

- 凡品：两条不同核心属性，随机roll。
- 灵品：主属性、道象伤害、指定触发。
- 仙品：以上+指定玄机。
- 道品：以上+共鸣计数灵纹、道品独有；总计5条灵纹+1独有。
- 新增65件主题为显式逐件表：主/次属性、道象、触发、玄机、道品共鸣码与独有码均明确指定，不按 ID 取模随机配身份。
- 属性范围统一 `AffixRange`，生成与道典共用。玄机仍沿用6种已实现机制，不虚构65种未执行特效；新增主题不是65种独立机制的承诺。
- 仅种类解锁，不做局间法宝带出。物品 `carryOut` 旧预留字段不代表本命系统已开放。

## 信息接口与测试

`DescribeSpell`（全部重数）、`DescribeAffix`（实例真实roll）、`DescribeRelic`（主题/品质范围/规则）、`DescribeResonance`、`DescribeFusion` 给 UI 共用。未祭炼实例的隐藏roll由 Economy管理；道典可公开规则，不泄露该实例roll。

离线检查：`bash scripts/test-full-content.sh`，`bash scripts/test-mvp-progression.sh`，`bash scripts/test-mvp-economy.sh`。新增测试覆盖目录30/80、真实配置、主题唯一、封存次数与永久移除、第二层gate、跳过原子领奖、第三角色融合计数继承、金4共鸣、发现数组尾部合并、永久基线及多洞主奖励幂等。旧测试不删除、不改变预期随机掉落口径。

## 字段消费矩阵与真实行为回归

新增模板按此矩阵审查；不是将字段列出来即视为实效。`tests/full_spell_behavior_tests.cpp` 在真实 Simulation 固定步长推进，并验证生命值、位置、效果/弹体状态变化。

| 配置字段 | 模板消费者 | 行为验证 |
|---|---|---|
| damage/cooldown | Cast → Hit/ScaleDamage、spellCooldowns | 全新增21配置路径均造成伤害（集成测试）；基础配置测试检查正值 |
| radius/coneDegrees | Cone朝向扇区；Projectile射程；Field/Talisman爆炸半径；Companion索敌范围 | 前方受伤后方不伤；远方符箓落点而非近身误用半径 |
| count | Projectile多柄、Companion多实体、Talisman多次带预警爆发 | 御兽五重两实体不同位置、符箓两次预警 |
| pierce/returning | ProjectileState穿透计数、返程分支 | 一次前进命中两敌；返程returned实际置位 |
| duration/interval/followPlayer | UpdateEffects持续跳伤，阵随身，御兽绕身 | 移动玩家后阵域位置跟随，御兽绕行并发弹 |

| healOnHit | Hit按真实命中回复 | 玩家气血实际增加，御兽弹体命中也回复 |

## 第二轮：心法配方类别与真实专属池

此前只有三条双圆满术法配方，不足以覆盖完整设计的“圆满术法＋指定心法”。现追加三条暂定路线，保留旧ID和三条双术法路线：

| 修士 | 条件 | 成品 | 执行模板 |
|---|---|---|---|
| 法体 | 焚心掌5重＋炼火心经 | 离明焚天掌 | 扇击55、1.2秒、半径4.5、麻痹.35秒，附火灼烧 |
| 飞剑 | 赤焰飞剑5重＋金罡经 | 赤霄逐日剑 | 3柄，每柄24、1.1秒、射程16、穿透6，附火灼烧 |
| 御兽 | 青鹿引灵5重＋长生经 | 青皇瑞鹿 | 2只，每击22、施展间隔7秒、存续8秒、攻击间隔.75秒、索敌11、减速25%、命中回1.2血、施展护盾5 |

**最小一致默认：心法不消耗。** 成品替换原术法，仍占1术法槽；心法仍占原心法槽。融合成品只继承被替换术法的道象计数，心法继续在心法循环中计一次，不把心法计数复制到成品内。上限仍6术法/4心法。持有配方心法时提高术法候选权重；术法5重时提高指定心法候选权重。CanFuse/Fuse、说明和发现记录统一来自FusionCatalog，不仅新增文案。

第二轮回归增加：三条心法融合前后计数、心法保留/槽位不增加、三成品真实伤害；软保底随波单调提高及MVP不变；65新主题分区完整且互斥；每个洞天所有品阶普通掉落、3个不同洞主奖励、坊市和宝匣均不越过合法池。

平衡风险：自然战斗烟测曾观察御兽双术法成型仍有较长洞主战，单seed不足以直接调数。所有新增数值继续标provisional，配置功能与规则覆盖不等同于8–12分钟节奏已完成多seed平衡验收。
