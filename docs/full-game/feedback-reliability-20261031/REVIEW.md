- 关闭弹窗先执行显式恢复，再检查真实焦点，避免后续无条件恢复覆盖失焦暂停。
- 开始/续接命令拒绝替换正在进行的战斗；已结束的局仍可重试。重试失败保留原局及结算界面并显示提示，新局清空上一局的临时选中和洞主提示状态。
