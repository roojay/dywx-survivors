## 新号Body：已知原因与尚未证明的事

- 原trace：100.024秒波2开场HP120.008、等级5；160.038秒HP113.496、等级6；190.048秒HP67.6442；215.791秒HP0、等级8。只读诊断累计受伤在上述后3点分别47.554、108.410、205.780。是持续战斗失血，不是血量NaN、阶段停滞或无原因瞬死。
- 波2刻意加压：`Campaign.cpp:39–51` Quick波1→2时健康倍率1→1.5，伤害1→1.15，cap40→70，并新增远程/冲锋角色数量。新号死亡前观察峰值65。
- 新号与全解锁近战不是同一数值基线的“唯一种子对照”：`Simulation.cpp:103–125` 按账户开启形态共鸣、额外重悟、法术/装备池、经济/异象等；永久属性均零不等于所有成长机会相同。`Progression.cpp:148–167` 限定新号池；不可用老号723秒胜替代新号验证。
- 原策略会取新炎身110分、烈焰阵90分、离火剑环85分，而早期起手素材75分（`full_game_playthrough.cpp:29–54`）；第2波死亡构筑5门术法多为1重、主掌4重，升级资源摊薄。policy1只增加起手素材30分，最终主掌5/雷拳4/炎身1、288.657秒波3死，延长72.866秒。这个合法反事实证明策略影响显著，但仍没有新手成功证据。
- 策略只在无Boss且最近敌人>4时主动捡经验（同文件130–138），对高密度与近战成长尤其保守。不要把机器不捡/分散升级直接解释为HP或伤害字段错误。

## 御兽：机制有效、策略失配、节奏仍待调

- 默认远程Boss距离6（harness约121–126）；炎身3重半径3.2（ContentCatalog.cpp:92–105），当前area1。御兽p0 Boss期30秒采样大多距离5–7，短程术法难以覆盖。Boss进场第一帧距离40.617属于生成位置，不计为稳定站位。
- 只读Hit日志总计约11968.52 Boss伤害，吻合14000−2032.85的舍入量级：WoodBeast657次/5692.00；WaterBeast46次/982.19；WaterArray634次/3105.39；FlameArray108次/1321.29；FlameBody7次/62.14；EarthPalm2次/24；Count来源（DOT等非术法直击，不应当作独立法术）7721次/781.49。因此“御兽伤害为零/所有新术法无效”不成立。
- Companion生成与实际投射物发射分别在 `Simulation.cpp:1314–1323`、`1637–1675`。宠物绕玩家2.2格，按自己的位置与spec.radius选目标，并偏好远程/爆炸怪（distance加权0.4），不是永远聚焦Boss。WaterBeast3重射程7.2，与6格主人距离及2.2环绕组合存在命中覆盖损耗；这是实际机制/策略配合，不足以定性实现错误。
- p0结尾Wood5/Water3，`Progression.cpp:262–270` 要求两素材均5才可融合；没有满足配方却拒绝融合的证据。
- p5只Boss靠近即在1010.73秒通关，Boss耗时490.80秒；p6原策略1273.99秒Boss战后胜。更靠近带来输出、击杀、后续自然升级、融合的联动，不能将p5归因于纯距离提高某固定百分比DPS。
- p3/p4从开局就更靠近反而更差，不能简单把所有御兽距6改3.2。需要按阶段、敌群密度、已持术法射程调整策略。
- 第一/二变HP默认14000/16000（Types.h约228–229；Simulation.cpp:670、1890–1892），本轮没有改它们。当前结果对8–12分钟节奏有负面证据，但不能从单种子一套机器策略推导全局buff倍率。
