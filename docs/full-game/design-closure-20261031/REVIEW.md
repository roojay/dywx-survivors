# 完整玩法设计复核与修复（2026-10-31）

## 范围

按用户要求继续实现完整玩法，不把首轮两英雄试玩范围当作功能完成豁免。对照 `../../gameplay-design-v0.1.md`、`../../mvp-prototype-config-v0.1.md`，基线 ff3452e。三路分别核查战斗规则、经济/账号/存档、玩家操作入口，先独立复现再修复；没有为自动通关调高伤害或削弱敌人。

## 本轮确定修复

1. **波次大妖在波末生成即清除**：单只计划原来只能在进度100%生成，同帧EndWave清空。改为单只65%、多只50%–80%的中后段分布，并在普通补怪前尝试到期大妖。失败不增加已生成计数，不突破敌人上限。
2. **飞剑追射程外目标**：旧赤焰/雷纹/融合飞剑主目标使用100格默认范围而实际射程更短。主副目标都使用真实术法射程；无合法目标沿用短等待重试，不浪费完整施法周期。
3. **灵兽中奖被满员吞掉**：保存成功抽中的待生成状态，有空位时先于普通补怪重试，不重新抽奖、不增中奖率、不挤掉现有敌人。跨Start/波末清除等待，不能把上一波中奖带到下一波。
4. **大妖机缘没有战前整理窗口**：选择后留在调息，玩家可换装/炼化，再明确迎战。大妖额外战斗不增加波号，胜后回同波整理，再迎战才推进下一波；未解决机缘不可存档跳过。
5. **公开迎战命令绕过顿悟门禁**：已有升级/赠宝/宝匣/重铸/未选机缘不能越过。炼化修为入账若产生新顿悟，仅提交修为并留在Rest，返回false表示尚未开战；重复调用不重复入账。波间存档原来的副本投影语义保留，待选顿悟仍可保存。
6. **跨角色旧档回滚账号保底**：恢复候选局使用最新账号保底覆盖旧值（不是取max），合并发现并清理旧波标志；校验完成后才持久消费，最后激活候选局。
7. **波间奖励吞下一波保底计数**：宝匣仙品只重置保底；成功退出整理时清理已完成战斗段的标志，覆盖大妖额外战斗和无尽洞主之后的边界。真实正在进行的战斗不能被无效EndRest清标志。
8. **存档与全局进度不同事务**：SaveRun在候选Profile合并本局全部发现和保底，再一次性写checkpoint，成功才替换内存Profile。与SaveProfile共用ObserveRunInto；不改结算ledger/存档schema。
9. **玩家信息与流程可读性**：明确“可破境”，按层级说明宝匣保证；区分迎战大妖/洞主/下一波。大妖额外战斗不再显示妖潮余时0，改为机缘标识及胜后整理提示。暂停菜单显示真实不可存原因，不把待选顿悟误禁用。
