局内：W1 世界地图以薄顶栏承载资源，任务在左上、行动提示在右下；T1 战术图把选中单位与技能排在底部，右侧另有统帅区域，技能说明向上展开；E1 事件图左侧承载标题、正文与纵向选项，右侧人物，另有嵌套说明。这说明“场景为主体、功能靠边、详细解释按需展开”是可借鉴的层级；不是所有页面都应复制成左栏。

## 五张原创转译

- **01 主菜单**：借鉴左侧窄导航／右侧人物；改为中国神话山门、青铜与玉色，不复制账号、社交或 DLC 系统。
- **02 修士选择**：借鉴列表加大角色预览；收敛为三种修士与起手术法，不搬运复杂派系定制。
- **03 洞天设置**：把领域列表与简要设置合并；洞天景观为视觉主体，模式、层级为次级项，进阶设置折叠。
- **04 战斗 HUD**：借鉴边缘锚定与紧凑技能栏；改为即时生存战的气血、妖潮与遁术，不保留回合按钮、六角格和帝国资源。
- **05 暂停顿悟**：借鉴事件的左侧选择／右侧叙事图；三选一、明确暂停、确认后继续。暂停与升级规则是我们的设计，不是 AoW4 观察结果。
