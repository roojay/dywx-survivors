# 五屏概念实施素材

设计参考：`docs/design/aow4-inspired-20261031/01-main-menu.png` 至 `05-paused-upgrade.png`。用户已明确要求按该套布局重做。这里记录内置 image_gen 生成的资源与提示；不使用外部收费API。

所有 `Content/UI/Images/concept-*-bg.png` 都是无文字、按钮、Logo或图标的独立绘景。它们只能供菜单/选择/顿悟阅读界面使用；实际文字、数值、选中态、锁定与点击必须由Slate绘制。战斗仍实时渲染，不得用概念战斗截图替代。

- main：主菜单右侧角色近景；sword/body/beast：三修士不同立绘场景。
- thunder/ember/mist：三洞天门景，构图一致；实际银绿/朱砂/雷蓝色调。
- upgrade：右侧冥想人物，左侧供候选文字。光环可能延伸至55%处，原生UI需适当加深左侧渐变保证可读。
- portraits：三列等分方形头像，顺序Body/Sword/Beast；实际2172×724，使用归一化三分之一UV，不假设固定512像素。

绘景原始输出1672×941，不是提示请求的1920×1080；保留原始比例，不做离线拉伸。主界面按同一画布比例缩放/留边或使用适当裁切，不能把文字与按钮一起烘焙放大。

图片是二维原画，不暗示人物可实时旋转、天气为实时3D或已经达到战斗模型同等细节。纹理纯像素验证不替代真实720p/1080p交互/布局验收。原始生成文件保留于制作工作区；各子目录记录提示和哈希。
