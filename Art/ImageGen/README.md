# 目标风格美术纹理（2026-10-31）

按用户提供的当前游戏截图与目标风格图制作：斜俯视、风格化三维东方神话庭院，冷色雕刻石材、暗铜、暖火光、白衣角色与紧凑圆形技能图标。原参考用于风格方向，不把参考图贴成战斗背景，不宣称生成图片是UE实机画面。

使用内置 image_gen，非收费 API 脚本。三个原始生成PNG已保存到 manifest 所列游戏路径，石材与符纹通过真实UV及 M_Courtyard 采样，HUD使用3×2图集裁切。最终提示的内容摘要、实际文件字节和SHA256保存在 manifest.json。

石材和符纹输出实际为1254×1254 RGB（不同于提示请求的2048），UE导入时设置构建拉伸至二次幂、mipmap和三线性过滤，避免填充产生边缘缝。生图要求无缝不等于已保证无缝，需要实机场景检查重复接缝。图标实际1536×1024 RGBA，每格512×512；已检查六格透明角区与主体alpha，未用后期脚本抠图。不得将图集中不对应的细节当作玩家技能效果承诺。

这些是材质与UI资源，不替代Blender立体模型、动作、UE光照或性能验收。Blender预览只能标记为离线预览；交付应另附正常打包UE运行截图。
